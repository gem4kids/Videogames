# Instrucciones para el Asistente (Claude)

## Sobre el proyecto
Este es un proyecto de Python estructurado de forma estándar. El código principal vive en la carpeta `src/` y las pruebas en `tests/`.

## Estilo de Código
1. **Idioma:** Escribe todo el código en Python 3. 
2. **Nomenclatura:** Usa `snake_case` para variables y funciones (ej. `calcular_total`), y `PascalCase` para las Clases (ej. `UsuarioNuevo`).
3. **Comentarios:** Todos los comentarios y explicaciones en el código deben estar en Español.
4. **Tipado:** Usa siempre "Type Hints" de Python (ej. `def sumar(a: int, b: int) -> int:`).
5. **Simplicidad:** Escribe código claro, directo y fácil de leer para un principiante. Evita soluciones demasiado complejas si hay una forma sencilla de hacerlo.

## Comandos del Proyecto
- Para ejecutar el archivo principal: `python src/main.py`
- Para instalar dependencias: `pip install -r requirements.txt`
