Bienvenido a **Videogames**, un repositorio dedicado a la experimentación, desarrollo y personalización de videojuegos clásicos utilizando **Claude Code** como asistente principal de programación.

## 🎯 Objetivo del Proyecto

Este proyecto nace como un entorno de entrenamiento para dominar el uso de Inteligencia Artificial en el desarrollo de software. El enfoque principal es:
- Delegar la creación de la lógica base de videojuegos a la IA.
- Aprender a refactorizar y añadir mecánicas personalizadas mediante "prompts" precisos.
- Mantener buenas prácticas de la industria (entornos virtuales, control de versiones con Git/GitHub y código limpio).

## 👾 Juegos Incluidos

Actualmente, el repositorio incluye las siguientes personalizaciones:

* **Pong Clásico (`src/pong.py`)**: Una recreación del mítico juego arcade con físicas de rebote, control de dos jugadores y sistema de puntuación, generado íntegramente a través de instrucciones en lenguaje natural.

*(Se irán añadiendo nuevos juegos y mecánicas a medida que avance el entrenamiento).*
